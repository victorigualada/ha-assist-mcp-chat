# Project Design Context

## Design Context

### Users
Home Assistant power users and developers running an LLM conversation agent wired to the
ha-mcp tool server. They use a right-side chat drawer, opened inside the normal HA UI, to
control and inspect their smart home and to do configuration / "coding"-style tasks. They
care about *what the model actually did* — which tools it called, with what arguments, and
what came back — not just the final sentence.

### Brand Personality
Home Assistant first. The drawer is embedded in HA's frontend, so it must inherit the
user's active theme (light / dark / custom) through HA CSS custom properties and HA
components. Within that constraint the personality is an **agent console**: precise,
transparent, developer-respecting. It shows its work without shouting. Three words:
*transparent, structured, calm*.

### Aesthetic Direction
- **Theme tokens only.** Color, surface, divider, and type all come from HA variables
  (`--primary-text-color`, `--secondary-text-color`, `--card-background-color`,
  `--secondary-background-color`, `--divider-color`, `--primary-color`, `--error-color`,
  `--ha-font-*`, `--ha-border-radius-*`). Never hardcode a brand color or font — that would
  fight every user theme and read as a foreign object.
- Distinct character comes from **structure, not palette**: a reason → act → answer activity
  stream, monospace for tool names / args / JSON, quiet status indicators, and clear rhythm
  between turns.
- Theme (light/dark) is whatever the user's HA is set to — inherited, never chosen here.
- Anti-references: a generic chatbot bubble UI; a noisy always-on debug log.

### Design Principles
1. **Native first.** Every spacing, color, and font traces to an HA theme token.
2. **Show the work, quietly.** Reasoning and tool calls are first-class but collapsed by
   default — depth on demand, never noise by default.
3. **Legible rhythm.** Unmistakable separation between user and assistant turns, and within
   an assistant turn between thinking, tool activity, and the answer.
4. **Motion with restraint.** Transform/opacity only, exponential ease-out, honor
   `prefers-reduced-motion`. Status uses a single calm pulse, not spinners everywhere.
5. **No AI-slop tells.** No colored left-stripe accents, no gradient text, no decorative
   glassmorphism. Borders, background tints, and leading glyphs instead.
